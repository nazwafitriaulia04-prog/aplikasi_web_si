Penjelasan Arsitektur Post/Redirect/Get (PRG)

Ketika pengguna menekan tombol submit, browser mengirim request HTTP POST ke server. Alih-alih merender HTML langsung dari respon POST, server mengembalikan status HTTP 302 Redirect ke URL tujuan dengan metode GET. Dengan cara ini, riwayat peramban tetap bersih dan tombol Back/Refresh tidak akan memicu resubmisi data ganda.
